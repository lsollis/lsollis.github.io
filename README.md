# lsollis.github.io

Source for [lsollis.github.io](https://lsollis.github.io), the academic portfolio of Lydia J. Sollis
(Ph.D. student, Computer Science, University of Hawaiʻi at Mānoa).

Built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io)
template and deployed by GitHub Actions (`.github/workflows/jekyll.yml`) on every push to `master`.

- Pages: `_pages/` · Publications: `_publications/` · Talks: `_talks/` · PDFs: `files/`
- Local preview: `docker compose up` (see `docker-compose.yaml`), or `bundle install && bundle exec jekyll serve`.
